# Shaale-Vikas

Shaale-Vikas is an Android-based mobile application developed to support school infrastructure development through community participation and transparent digital communication.

## Features
- Admin Login
- Add School Needs
- View Development Requirements
- Pledge Support
- Donor Hall of Fame
- Gallery Section
- Real-time Firebase Database Integration

## Technologies Used
- Kotlin
- Android Studio
- Firebase Realtime Database
- XML Layouts
- Gradle

## Project Objective
The main objective of the project is to create a transparent platform where schools can publish infrastructure requirements and community members can support development activities.

## Modules
1. Login Module
2. Needs Dashboard
3. Pledge Support Module
4. Donor Hall
5. Gallery Module

## System Architecture
The application follows a three-layer architecture:
- Presentation Layer (Android UI)
- Application Logic Layer
- Firebase Backend Layer

## Database
Firebase Realtime Database is used for:
- School needs storage
- Donor information
- Progress updates
- Real-time synchronization
